# Deep Learning & Computer Vision Lab – WorldQuant University

A collection of deep learning and computer vision projects completed as part of the WorldQuant University MSc in Financial Engineering programme.

## Projects

### 1. Crop Disease Classification
- Classified crop images into five disease categories.
- Implemented Convolutional Neural Networks (CNNs) and transfer learning for image classification.

### 2. Traffic Monitoring
- Applied a pre-trained YOLO object detection model to traffic footage.
- Detected and identified vehicles and pedestrians in video frames.

### 3. Face Detection and Recognition
- Used MTCNN for face detection.
- Applied FaceNet (Inception-ResNet V1) for face recognition in video footage.

### 4. Medical Image Generation
- Experimented with Generative Adversarial Networks (GANs) to generate synthetic X-ray and MRI images.
- Developed an interactive Streamlit application for exploring generated images.

## Technical Stack

- **Programming:** Python
- **Deep Learning:** CNNs, Transfer Learning, GANs
- **Computer Vision:** YOLO, MTCNN, FaceNet
- **Libraries & Frameworks:** PyTorch, TensorFlow, OpenCV, Streamlit

## Repository Structure

The repository contains individual notebooks and implementation files for the computer vision and deep learning assignments.

## Learning Areas

- Image classification and feature extraction
- Object detection in video streams
- Face detection and recognition
- Generative modelling for medical imaging
- Deep learning model implementation and evaluation
